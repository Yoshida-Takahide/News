# AI News Archive

Claude Code / Anthropic および LLM・AI 研究の最新情報を定期収集したアーカイブです。

## カテゴリ

| ファイル名パターン | 内容 | 主なソース |
|---|---|---|
| `*_claude-code_news.md` | Claude Code・Anthropic の公式発表・リリースノート | Anthropic 公式ブログ、リリースノート、アライメント研究 |
| `*_llm-news.md` | LLM・AI 研究の最新動向 | Andrej Karpathy (X/ブログ)、Stanford・MIT・Berkeley・arXiv |

## ファイル命名規則

```
YYYYMMDD_HHMMSS_<カテゴリ>.md
```

例: `20260511_220708_claude-code_news.md` → 2026年5月11日 22:07:08 収集の Claude Code ニュース
